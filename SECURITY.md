# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub: go to the [Security tab](https://github.com/safecircleia/orbit/security/advisories/new) of this repository and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the affected version or commit. We will acknowledge your report and keep you updated as we work on a fix.
