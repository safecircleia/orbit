# Orbit 0.2 Beta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Orbit 0.2b: SafeCircle onboarding, privacy hardening, family/school policies, correct versions and notes, verified on a Slurm-built artifact.

**Architecture:** Orbit-specific behaviour ships as prefs (`prefs/**/*.yaml`, compiled into `engine/browser/app/profile/zen.js` by `bun run ffprefs`) and as git patches in `src/` (captured from `engine/` with `git diff`, never committed in `engine/`). A single stdlib Python script, `scripts/check_orbit_config.py`, asserts the config in the repo (red/green per task). The final build runs on the Slurm cluster via the existing `orbit-rebuild.sbatch`.

**Tech Stack:** Firefox 157.0 source via Zen Surfer, YAML prefs, git patches, `policies.json`, Python 3 stdlib, bun, Slurm (host `Slurm-Copy`, user `jtpalma`, partition `cpuMax`).

**Spec:** `docs/superpowers/specs/2026-10-04-orbit-0.2-beta-design.md`

## Global Constraints

- Never edit `engine/` and leave it dirty: edit, capture with `git diff <path> > ../src/<...>.patch`, then `git checkout <path>` (and remove new files). `CLAUDE.md` rule.
- `bun run import` must show `[FINISH]` for every patch.
- New source files carry MPL-2.0 headers (`bun run lc`); Prettier: 2-space indent, 100 cols, single quotes; Python: autopep8, 2-space indent like `scripts/run_tests.py`.
- Firefox 157.0; beta brand `Orbit Browser Beta`; display version `0.2b`.
- DoH: `network.trr.mode=2`, `network.trr.uri=https://security.cloudflare-dns.com/dns-query`.
- HTTPS-only on; ETP `strict`; `privacy.fingerprintingProtection` on; `privacy.resistFingerprinting` untouched (off).
- Fullscreen warning restored: remove `full-screen-api.warning.delay` / `warning.timeout` overrides, keep the `0 0` transition overrides.
- Policies: `BlockAboutConfig`, safe-search default engine, uBlock Origin (`uBlock0@raymondhill.net`) locked.
- Onboarding screens, in order: Welcome + privacy promise, set as default browser, import data, theme. No Mozilla promo, sync or VPN screens.
- Commits, pushes and the cluster sync happen only once the user has approved the execution method. Ask before `git push`.

## Spec deltas (found while planning)

- **About dialog:** already patched (`about/aboutDialog-xhtml.patch` removes the Mozilla links, links safecircle.tech). No new work; smoke test confirms.
- **Error-page palette: deferred.** The repo defines no Orbit accent colour (only the `#2B2A33` background), and inventing one is a design decision. Not in this plan.
- **First-run page:** branding sets `startup.homepage_welcome_url` to `https://safecircle.tech/orbit`, which would bypass `about:welcome`. Task 3 points it back at `about:welcome`.
- **Default search engine:** the spec did not name one. This plan uses **DuckDuckGo with strict safe search** (`kp=1`). Change the `policies.json` entry in Task 2 if SafeCircle prefers another.
- **Theme screen:** Firefox only targets `AW_THEME_PICKER` when `browser.nova.enabled`; Task 3 removes that targeting. Wallpaper choice stays in the new-tab customise panel (the picker is light/dark/system themes).

## Review Focus

Failure modes the spec implies but nothing in it exercises; each is pinned in the owning task.

1. `policies.json` malformed: Firefox then ignores **all** policies silently (`about:config` open, uBlock removable). Task 2 parses the JSON in the check script and the smoke test reads `about:policies`.
2. DoH provider unreachable (offline, captive portal, school firewall): mode 2 must fall back to system DNS so browsing still works. Task 1 pins `mode == 2`; smoke test confirms the pref in the built artifact.
3. HTTPS-only on an HTTP-only site: user sees Firefox's interstitial and can proceed, not a dead end. Smoke test step.
4. Onboarding on a machine where Orbit is already the default browser or there is nothing to import: reused screens keep their `targeting`, so they are skipped rather than shown empty. Task 3 check asserts `targeting` is preserved for those screens.
5. Existing 0.1b profiles: onboarding must not reappear (first-run page is new-profile only), while the new prefs do apply. Smoke test relaunches the same profile.

```python
#!/usr/bin/env python3
# This Source Code Form is subject to the terms of the Mozilla Public
# License, v. 2.0. If a copy of the MPL was not distributed with this
# file, You can obtain one at http://mozilla.org/MPL/2.0/.

"""Static checks for Orbit's release config. Run: python3 scripts/check_orbit_config.py"""

import pathlib
import re
import sys

ROOT = pathlib.Path(__file__).resolve().parent.parent
CHECKS = []


def check(fn):
  CHECKS.append(fn)
  return fn


def text(path):
  return (ROOT / path).read_text()


def pref_value(name):
  pattern = re.compile(r'^- name: ' + re.escape(name) + r'\n  value: (.+)$', re.M)
  for yaml_file in (ROOT / 'prefs').rglob('*.yaml'):
    match = pattern.search(yaml_file.read_text())
    if match:
      return match.group(1).strip()
  return None


@check
def fullscreen_warning_not_suppressed():
  assert 'full-screen-api.warning' not in text('prefs/firefox/fullscreen.yaml'), \
      'fullscreen warning overrides still present'


@check
def hardening_prefs():
  expected = {
      'dom.security.https_only_mode': 'true',
      'browser.contentblocking.category': "'strict'",
      'privacy.fingerprintingProtection': 'true',
      'network.trr.mode': '2',
      'network.trr.uri': "'https://security.cloudflare-dns.com/dns-query'",
  }
  for name, value in expected.items():
    assert pref_value(name) == value, f'{name}: {pref_value(name)!r} != {value!r}'


@check
def resist_fingerprinting_untouched():
  assert pref_value('privacy.resistFingerprinting') is None


if __name__ == '__main__':
  failed = 0
  for fn in CHECKS:
    try:
      fn()
      print(f'ok   {fn.__name__}')
    except AssertionError as error:
      failed += 1
      print(f'FAIL {fn.__name__}: {error}')
  sys.exit(1 if failed else 0)
```

```python
def patch_added_file(patch_path, file_path):
  section = text(patch_path).split(f'+++ b/{file_path}\n', 1)[1].split('\ndiff --git', 1)[0]
```

```js
// Orbit onboarding: welcome, then Firefox's default-browser, import and theme
// screens on a plain background with no sign-in or backup-restore buttons.
function getDefaults() {
  const reusedScreens = MR_ABOUT_WELCOME_DEFAULT.screens
    .filter(({ id }) => ORBIT_REUSED_SCREENS.includes(id))
    .map(({ id, targeting, content }) => {
      // eslint-disable-next-line no-unused-vars

          ...rest,
          position: "center",
          background: ORBIT_SCREEN_BACKGROUND,
        },
      };

    {
      ...MR_ABOUT_WELCOME_DEFAULT,
      screens: [ORBIT_WELCOME_SCREEN, ...reusedScreens],
```
