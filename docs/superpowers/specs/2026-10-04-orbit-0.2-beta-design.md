# Orbit 0.2 Beta — Design

Date: 2026-10-04 · Branch: `beta` · Base: Firefox 157.0

## Goal

Ship Orbit 0.2b as a browser that is clearly SafeCircle, safer by default for
families and schools, and release-ready (correct versions, notes, verified build).

## Scope

In: branding polish, privacy hardening, family/school defaults, release readiness,
verified Slurm build + smoke test.
Out (later projects): parental-control extension, SafeCircle account/sync, VPN.
Already done, not repeated: telemetry/Normandy/studies off, AI/ML off, Pocket and
sponsored content off (`prefs/privatefox/`, `prefs/firefox/ai.yaml`).

## Constraints

- Never edit `engine/` directly. Changes ship as `.patch` files in `src/` or as
  new files under `src/` / `prefs/` (see `CLAUDE.md`).
- `bun run import` must show `[FINISH]` for every patch; `engine/` stays clean
  when committed.
- MPL-2.0 headers on new source files (`bun run lc`); Prettier/ESLint pass.

## Design

### 1. Branding polish
- **Onboarding:** re-enable `browser.aboutwelcome.enabled` and replace Firefox's
  default screens with an Orbit flow by patching
  `browser/components/aboutwelcome/modules/AboutWelcomeDefaults.sys.mjs`. This reuses
  the built-in multi-screen `about:welcome` machinery (default-browser, import and
  theme actions already exist) instead of a hand-written page. Screens, in order:
  1. **Welcome + privacy promise:** SafeCircle-branded, lists what Orbit blocks
     by default, links to the safecircle.tech privacy page.
  2. **Set as default browser:** built-in default-browser action; skippable.
  3. **Import data:** built-in migration action (bookmarks, history,
     passwords); skippable.
  4. **Theme / look:** light, dark or system, plus new-tab wallpaper choice.
  All strings are Orbit-specific; no Mozilla promo, sync or VPN screens. Screen
  config is verified against Firefox 157 at plan time (message schema changes
  between releases).
- **About dialog:** extend the existing `about/` patches with SafeCircle support and
  privacy links; check the Firefox 157 wording for leftover Mozilla text.
- **Error/offline pages:** apply the Orbit palette (`#2B2A33`) via CSS patch.
- **Leftover "Zen" wording:** fix user-visible strings and `prefs/README.md`.
  Internal file/dir names (`zen-icons/`, `zen-preferences.css`) stay; renaming them
  only churns patch paths.

### 2. Privacy hardening (`prefs/privatefox/`)
- HTTPS-only mode on.
- Enhanced Tracking Protection: strict.
- DNS-over-HTTPS via **Cloudflare Security** (decided): `network.trr.mode=2`
  (DoH first, system DNS fallback) and
  `network.trr.uri=https://security.cloudflare-dns.com/dns-query`. It blocks known
  malware/phishing domains and does not filter adult content. Mode 2 keeps
  networks with their own DNS working. Trade-off: DoH bypasses school-network DNS
  filtering while Cloudflare is reachable; documented in release notes.
- `privacy.fingerprintingProtection` on; `privacy.resistFingerprinting` stays off
  (breaks too many school sites).
- **Restore the fullscreen warning** (security review finding, MEDIUM): in
  `prefs/firefox/fullscreen.yaml`, remove the `full-screen-api.warning.delay: -1`
  and `warning.timeout: 0` overrides so Firefox defaults (500 / 3000) apply.
  The instant-transition (`0 0`) overrides can stay. Without the warning, a page
  can go fullscreen and spoof browser UI (fake address bar or login prompt).

### 3. Family/school defaults (policies)
- Ship `distribution/policies.json` via a patch to
  `browser/app/distribution/moz.build` adding the file to
  `FINAL_TARGET_FILES.distribution`, and make `distribution/*` unconditional in
  `browser/installer/package-manifest.in` (upstream only packages it for
  `BUILT_BY_MOZILLA` builds, found when the first artifact lacked `distribution/`).
- Policies: default search with safe search, block `about:config`, lock uBlock Origin
  as installed/locked, keep private browsing available.
- Prefs remain the home for tunable defaults; policies carry only the locks.

### 4. Release readiness
- `surfer.json` beta `displayVersion` → `0.2b`.
- Rewrite `src/release-notes/` with real 0.2 entries and Firefox 157 (currently
  `0.0.1b` / Firefox 153).
- Review CI workflows: release/signing paths point at beta; Windows
  osslsigncode step still valid.

### 5. Build and verification
- Sync repo to `Slurm-Copy` (cluster host, user `jtpalma`), submit with `sbatch`
  on `cpuMax` (prior builds: ~3 min).
- Gate: `bun run import` all `[FINISH]`.
- Smoke test on extracted build: version/brand string, welcome page,
  `about:policies` (policies active), `about:config` blocked, HTTPS-only, ETP and
  DoH prefs effective, uBlock present, onboarding shows all four screens on a
  fresh profile and each skip/action works.

## Risks

- **Patch drift:** new patches against Firefox 157 may need hunk fixes —
  mitigated by running `bun run import` after each patch.
- **Policy lockdown vs. testing:** blocked `about:config` makes pref verification
  harder; verify prefs via `about:policies`/`about:support` or an unlocked dev build.
- **Onboarding schema drift:** `AboutWelcomeDefaults` message format changes
  between Firefox releases; the patch must be re-checked on every `update-ff`.
- **Strict ETP / HTTPS-only** may break some sites; documented in release notes
  under known issues.

## Testing

No unit-test surface (config + patches). Verification is import success, lint,
and the smoke test above on the cluster-built artifact.
